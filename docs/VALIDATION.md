Initialisation en arrière-plan : les callbacks Android du SDK 3.8.0 attendent le démarrage d’une activité avant de terminer une initialisation sans session. AndroidCoran termine cette étape indépendamment des écrans et gère la pause/reprise du renouvellement avec ProcessLifecycleOwner ; WorkManager peut ainsi attendre awaitReady sans ouvrir une activité. Source SDK : https://github.com/supabase-community/supabase-kt/blob/3.8.0/Auth/src/androidMain/kotlin/io/github/jan/supabase/auth/setupPlatform.kt . Le test public a réussi sans ActivityScenario et sans proxy pour couvrir ce cas ; la reprise d’une session authentifiée reste non validée. Le relais HTTPS et le proxy de diagnostic ont été retirés de l’émulateur.
